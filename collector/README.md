# Collector

이 폴더는 예약 실행, 검색 페이지 캡처, 순위 추출을 대시보드와 분리하기 위한 계약을 담습니다.

실제 네이버 화면 수집 어댑터를 연결할 때는 다음 원칙을 지켜야 합니다.

- 네이버 이용약관과 robots 정책을 검토합니다.
- CAPTCHA나 접근 제한을 우회하지 않습니다.
- 검색 빈도와 동시 실행 수를 제한합니다.
- 위치, 쿠키, 로그인 여부, 화면 크기를 수집 기록에 남깁니다.
- 실패 결과도 삭제하지 않고 다음 예약 시 재시도 대상으로 남깁니다.
- 스크린샷에는 계정·쿠키·개인정보가 나타나지 않게 합니다.

`SearchCaptureAdapter`를 구현하면 예약 실행부와 저장부를 바꾸지 않고 수집 방식을 교체할 수 있습니다.
